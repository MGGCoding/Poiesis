# Archive: version 1 (built 25 Sep 2026)

A snapshot of the calendar and `index.json` as they stood before revision v2 (29 Sep 2026): 21 days, each with one poem, passage and painting chosen from the Greek Orthodox Gospel of the day.

Every v1 work is still in `../../works/`, and the links in these archived day files point there, so every work stays available for reuse. The live calendar keeps the v1 days that were not revised (28–29 Sep and 10–18 Oct). The v1 choice for each revised day is option A there.
